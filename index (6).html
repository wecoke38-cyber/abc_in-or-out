엑셀 파일(「일별 근태 현황」)을 올리면 자동으로 계산됩니다
📌 이 화면 사용법
① 파일 받는 방법
ARS > 매장 > 일별근태현황 > 다운로드 → 받은 엑셀 파일을 아래 업로드 칸에 그대로 올려주세요.

② 이 화면이 계산하는 방식
  • 연차: 연차 1일 + 반차 0.5일 + 반반차 0.25일을 더해서 "사용일수"로 보여줍니다. 2024년 12월 31일 이전 입사자는 필수사용일수가 12일로 고정, 그 이후 입사자는 회사 자료에 없어서 직접 숫자를 입력해야 합니다.
  • 대체휴무(공휴일 포함): 법정공휴일(신정, 설날, 삼일절, 어린이날, 부처님오신날, 지방선거일, 현충일, 제헌절, 광복절 등, 노동절은 제외)에 실제로 근무했으면 "발생", 「휴일의 대체」로 쉬었으면 "사용"으로 계산합니다. 남은 개수(잔여)는 "발생은 됐는데 아직 안 쓴 건수"를 그대로 센 것입니다.
  • 색깔: 🔴 빨강 = 데이터에 확인이 필요한 부분이 있음(비고란 확인 필요) · 🟠 주황 = 연차를 아직 다 안 썼거나 필수일수가 입력 안 됨 · 🟢 초록 = 정상
📂 여기를 클릭하거나 엑셀 파일을 끌어다 놓으세요

원자료에 없는 값이라 자동 계산이 불가능해 직접 입력이 필요합니다. 입력값은 이 브라우저에만 저장되며, 새 파일로 갱신할 때마다 다시 넣어야 합니다.

산출 기준 · 연차 = 연차 1일 + 반차 0.5일 + 반반차 0.25일 (이월 건 제외) · 필수사용일수 = 2024-12-31 이전 입사자 12일 고정, 이후 입사자는 직접 입력 · 대체휴무 발생 = 재직기간 내 법정공휴일 중 실제 근무한 날(공휴일휴무는 발생과 동시 사용) · 잔여 = 발생 날짜 중 아직 사용되지 않은 건수 · 데이터 중복/누락으로 확인이 필요한 건은 빨간색으로 표시됩니다.
