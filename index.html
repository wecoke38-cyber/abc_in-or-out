📋 경남지역 연차·대체휴무 현황

🛠 신규 입사자(2025년 이후) 필수 연차사용일수 일괄 입력

사번,일수 형식으로 한 줄에 한 명씩 입력하세요. 예) 2510083,5
이 값은 원자료(엑셀)에 없어 자동 계산이 불가능해 직접 입력이 필요합니다. 입력값은 이 브라우저에만 저장되며, 새 파일로 갱신할 때마다 다시 넣어야 합니다.

산출 기준 · 연차 = 연차 1일 + 반차 0.5일 + 반반차 0.25일 (이월 건 제외) · 필수사용일수 = 2024-12-31 이전 입사자 12일 고정, 이후 입사자는 직접 입력 · 대체휴무 발생 = 「공휴일휴무」 + 근무일 중 비고에 미래 사용예정일이 적힌 건 · 사용 = 「공휴일휴무」 + 「휴일의 대체」(이월 제외) · 잔여가 음수인 경우 비고란 자유텍스트 표기 특성상 매칭이 안 된 것일 수 있어 원본 비고란 확인이 필요합니다.
