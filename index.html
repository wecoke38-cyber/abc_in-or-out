📋 경남지역 근태 조회

엑셀 파일을 올리면 대상 기간과 인원이 표시됩니다
❔ 처음이신가요? 이렇게 사용하세요
1. 파일 올리기「일별 근태 현황」엑셀을 선택하거나 끌어다 놓으세요.
2. 자동 계산파일 내용은 이 브라우저 안에서만 계산되고, 어디로도 전송되지 않아요.
3. 이름 검색검색창에 이름·사번을 입력하고 카드를 눌러 펼치면 상세 내역이 나와요.

색상이 뭘 뜻하나요? 🔴 빨강은 필수사용일수보다 연차를 더 썼거나, 대체휴무 사용이 발생 건수보다 많은(잔여가 음수인) 경우로 확인이 필요해요. 🟠 주황은 아직 다 쓰지 않은 필수 연차가 남아있다는 뜻이에요. 🟢 초록은 정상이에요.

필수사용일수 칸에 "–"만 보여요. 2025-01-01 이후 입사자는 필수사용일수가 원자료에 없어서, 카드 안 입력칸이나 아래 "일괄 입력"에서 직접 숫자를 넣어야 계산돼요.

다음 달 새 파일은요? 아래 "다른 파일 업로드" 버튼으로 새 엑셀을 다시 올리면 돼요.

산출 기준
· 연차 사용일수 = 연차 1일 + 반차 0.5일 + 반반차 0.25일 (근무상태 필드 기준)
· 연차 필수사용일수 = 입사일 2024-12-31 이전 12일 고정 · 2025-01-01 이후는 직접 입력
· 대체휴무 발생 = 「공휴일휴무」 건수(발생과 동시에 그날 바로 사용) + 「근무/타매장 지원근무」 중 마감수정사유·비고에 그 행의 날짜보다 미래인 날짜(YYYY-MM-DD)가 적힌 건수(공휴일 출근 후 대체일을 나중에 쓰기로 한 경우)
· 대체휴무 사용 = 「공휴일휴무」 건수 + 「휴일의 대체」 상태 건수
· 마감수정사유·비고에 "이월"이 포함되었거나, 그 해보다 이전 연도(예: 2025, 25년)가 언급된 행은 연차·대체휴무 사용 집계에서 제외(전년도 이월분으로 판단)
· 소속 매장은 대상기간 내 가장 최근 기록 기준
· 확인 필요로 표시되는 경우: 위 규칙은 실제 데이터 88명 기준으로 검증해 대부분 정확히 맞아떨어지지만, 자유텍스트 입력 특성상 100% 완벽하지는 않아요. 대체휴무 잔여가 음수로 나오면 이 앱이 그 행을 못 찾은 것일 수 있으니, 카드를 펼쳐 해당 직원의 비고란을 직접 확인해주세요.
